# TanglePuzzle - Co-op Mosaic Puzzle Game

A cooperative multiplayer puzzle game built with React, react-konva, and Socket.IO.

## Features

- Real-time co-op rooms
- Snap-to-place mechanics
- Zoom and pan
- 4 built-in images + custom upload
- 3 difficulty levels (24/48/80 pieces)

## Quick Start

1. Install all dependencies:
   ```bash
   npm run install:all
   ```
2. Start the server (Terminal 1):
   ```bash
   npm run dev
   ```
3. Start the client (Terminal 2):
   ```bash
   npm run dev:client
   ```
4. Open two tabs to [http://localhost:5173](http://localhost:5173)
